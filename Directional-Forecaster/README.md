# 📈 Closing Price Forecasting

A python project built to analyze historic stock trends and forecast the closing price of any stock (that is provided by YFinance). Not for official use, but rather for research purposes.

## 🛠️ Tech Stack

* **Python 3.8+**
* **YFinance** - Finance data
* **Pytorch** - LSTM model
* **Matplotlib** - Graphing system
* **OS** - Saving model profiles
* **Datetime** - Adding date to saved LSTM models
* **Pandas** - Dataframes
* **Numpy** - Configuring tensors
* **Collections** - Store dates as list in dict
* **Sklearn** - Linreg
* **Tkinter** - UI interface
* **Threading** - Handle multiple processes (Interface & LSTM)
